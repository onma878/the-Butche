# 🥩 THE BUTCHER

**A Modern Butcher Shop Website**

THE BUTCHER is a responsive butcher shop website designed to showcase meat products and provide customers with a simple and interactive shopping experience.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices.
- Product catalog with multiple meat categories.
- Interactive product filtering.
- Product details displayed in a modal.
- Shopping cart with quantity selection.
- Automatic cart total calculation.
- Add and remove products from the cart.
- Interactive order form.
- Smooth animations and visual effects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- AOS Animation Library
- iTyped.js
- Font Awesome

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/onma878/the-Butche.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.

## 📌 Project Status

The website is published using GitHub Pages.

The current version is a front-end project. The order form is not connected to a backend service yet.
